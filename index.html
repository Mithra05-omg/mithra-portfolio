TrackEd

Student progress portal for secondary schools. My final year project at UKM.

Final year project
Final year projectPHPMySQLJavaScriptPDOBcrypt
Problem, solution and features
Problem
In secondary schools, attendance, discipline, homework and marks are often recorded separately, and parents rarely see their child's progress in one place.
Solution
A web portal with three roles. Teachers record attendance, discipline, homework and marks. Parents see everything in one dashboard. Admins manage users, classes and timetables.
Features
Role-based access, PT3 and SPM grading, class average comparison, timetable, Excel export, and secure login (Bcrypt, prepared statements, session timeout). Tested with real users, improved after a supervisor demo, and deployed to the university server.

Auditrix

An audit platform concept and working prototype for the NTT Data audit challenge. Built in a team of two.

Challenge project
Challenge projectHTMLCSSJavaScriptSVG charts
Problem and solution
Problem
Ticket audits are manual, and different auditors give different scores for the same ticket.
Solution
A weighted scoring rubric for four ticket types, with an 80-point auto-flag and critical criteria that force human review. Auditors agree with or override a flag with a required reason, and flags nobody answers within 4 hours move to the least-loaded auditor. I built the seven-page front-end prototype.

Problem and solution
Problem
Sellers update products and stock by hand on each marketplace, which causes mistakes and wasted time. The ERP needed one place to manage all channels.
Solution
Modules for product listing, inventory sync, order management and fulfillment, on a unified multi-channel database design. OAuth 2.0 for secure API access, and a bulk copy with validation that moves thousands of products between channels. I also fixed sync issues on live client stores.
